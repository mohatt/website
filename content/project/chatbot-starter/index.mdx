#### Project Overview

**Chatbot Starter** is a full‑stack AI chatbot starter with RAG, file uploads, and project‑scoped chats, built on **Next.js**, **Vercel AI SDK**, **Postgres**, and **Upstash Vector**.

Check out [the project repository](https://github.com/mohatt/chatbot-starter) on Github for more info.
