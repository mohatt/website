#### About the client

Glen Echo Fine Foods Inc. distributes a wide range of specialty foods with an emphasis on cheese and related products for both retail and foodservice. They carry 400+ different cheeses in stock and can supply many more.

#### Project description

A responsive, touch-first web app deployed as **interactive kiosks** on iPad and iPod touch devices in supermarkets across Canada. Shoppers can browse featured cheeses, view details, and sign up for Glen Echo’s newsletter.

#### My role & responsibilities

I served as the lead developer alongside two teammates.

- Converted design mockups and UX flows into a fully functional, responsive web app using the **Symfony** framework (with **Bootstrap**).
- Built a simple, rule-based **recommendation engine** that uses user inputs to suggest cheese types and surface related products on each cheese page.
- Developed an **admin dashboard** to manage the cheese catalog and application settings.
- Set up **automated deployments** and environment configuration for consistent releases.
