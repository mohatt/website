#### Project Overview

Built a **responsive, touch-first kiosk web app** for **Glen Echo Fine Foods**, a Canadian specialty-foods distributor. Deployed on **iPad/iPod touch** in supermarkets across Canada, the app lets shoppers browse featured cheeses, view details, and sign up for the newsletter.

#### Scope & Contributions

- **Frontend (Bootstrap/JS)** — Converted design mockups and flows into an accessible, responsive UI optimized for touch interaction.
- **Backend (Symfony/PHP + MySQL)** — Implemented catalog, product detail, newsletter capture, and admin endpoints with validation.
- **Recommendation engine** — Built a simple **rule-based recommender** that uses shopper inputs to suggest cheese types and related products.
- **Admin dashboard** — Tools for managing the cheese catalog and application settings.
- **Deployments** — Set up **automated deployments** and environment configuration for consistent releases.

#### Outcomes

- **Frictionless in-store discovery** with touch-friendly browsing and guided recommendations.
- **Lower maintenance overhead** via a clear admin dashboard and automated releases.
- **Consistent brand experience** across multiple kiosk devices and store locations.
