#### Project Overview

Built a **B2B marketplace** for wholesale electronics. The platform enables vetted buyers and sellers to list, discover, and transact efficiently, with automation around inventory visibility, pricing, and order workflows.

#### Scope & Contributions

- **Backend (TypeScript/Express)** — Implemented services for listings, search, pricing, and order workflows with clear contracts and validation.
- **Data visualization (D3)** — Built operational dashboards and charts to monitor inventory, pricing trends, and marketplace activity.
- **Admin tooling** — Internal tools for catalog management, approvals, and user/role administration.
- **Performance & SEO** — Optimized critical paths for fast page loads and indexable content.
- **Infrastructure on AWS (IaC)** — Provisioned environments and CI/CD for predictable, repeatable deployments; load-balanced web tier, static asset hosting/CDN, and centralized logging/monitoring.

#### Outcomes

- **Reduced manual operations** via automation across listing, pricing, and moderation flows.
- **Faster iteration** with typed contracts and a modular codebase.
- **Stable, scalable operations** on **AWS** with predictable releases.
